# Publications 관리 가이드

논문은 **Pages CMS(웹 편집기)** 로 등록합니다. git이나 JSON을 직접 다룰 필요가 없습니다.

가장 중요한 원칙이 하나 있습니다. **저자와 제목, 저널명을 따로 적지 않습니다. Google Scholar가 만들어 준 APA 인용문을 통째로 붙여넣습니다.** 아래에서 자세히 설명합니다.

## 1. 어디에 넣을지 고르기

CMS 왼쪽에 Publications가 네 개로 나뉘어 있습니다. **여기서 고른 것이 곧 사이트의 탭**이 됩니다. 예전처럼 "종류" 드롭다운을 따로 고르지 않습니다.

| CMS 항목 | 사이트 탭 | 파일 |
|---|---|---|
| International Publications (국제 저널) | International Publications | `publications/international.json` |
| Domestic Publications (국내 저널) | Domestic Publications | `publications/domestic.json` |
| International Conferences (국제 학회) | International Conferences | `publications/int-conf.json` |
| Domestic Conferences (국내 학회) | Domestic Conferences | `publications/dom-conf.json` |

## 2. 인용문: Google Scholar에서 APA 가져오기

이 항목이 논문 정보의 전부입니다. 저자, 연도, 제목, 저널명, 권, 호, 페이지가 한 줄에 다 들어갑니다.

### 가져오는 법

1. [Google Scholar](https://scholar.google.com)에서 논문을 검색합니다
2. 검색 결과 아래의 **인용 아이콘(")** 을 누릅니다
3. 팝업에서 **APA** 줄을 통째로 복사합니다
4. CMS의 **인용문** 칸에 그대로 붙여넣습니다

손으로 고칠 것이 없습니다. 붙여넣고 끝입니다.

### 왜 이렇게 하나

사람마다 저자를 다르게 적으면 목록이 뒤죽박죽이 됩니다. 실제로 예전 데이터에는 `김인섭, 서준원, & 임현우`처럼 `&`를 쓴 것과 `황정윤, 임도훈, 임현우`처럼 안 쓴 것이 섞여 있었습니다. Scholar가 만든 문자열을 그대로 쓰면 형식이 저절로 통일됩니다.

덤으로 **권, 호, 페이지가 딸려 들어옵니다.** 예전에는 이 정보가 한 건도 없었습니다.

### 붙여넣은 뒤 확인할 것

Scholar도 가끔 틀립니다. 세 가지만 눈으로 봐 주세요.

- 저자가 빠지지 않았는지 (Scholar가 저자를 줄여 놓는 경우가 있습니다)
- 연도가 맞는지
- 저널명이 약어가 아닌 정식 명칭인지

### 국문 논문은 한글 그대로

한국 저널 논문은 Scholar에 **영문 제목으로** 올라와 있는 경우가 많습니다. 그대로 가져오면 사이트의 국문 논문 목록이 영어로 바뀝니다. **한글 표기를 쓰세요.**

```
황정윤, 김덕우, 임현우. (2026). 건물 에너지 분석을 위한 공공데이터 기반 단독형·단지형 건축물 분류 및
공간·속성 정보 통합. 대한건축학회 논문집, 42(6), 283-290.
```

권과 호, 페이지는 논문 첫 장이나 학회 홈페이지에서 확인해 채웁니다.

### 국내 학회는 직접 입력

국내 학회 발표는 Scholar에 거의 올라오지 않습니다. 아래 틀에 맞춰 직접 씁니다.

```
이도연, 임현우. (2026). 건물 운영진단을 위한 LLM기반 데이터 분석 방법론 설계.
2026년도 대한설비공학회 하계학술발표대회.
```

권과 페이지가 있으면 학회명 뒤에 붙입니다.

```
이현수, 김지영, 임현우. (2025). 열적 특성 기반의 개인 맞춤형 좌석 선택 시스템 제안.
한국태양에너지학회 추계학술발표대회, 45(2), 72.
```

## 3. APA 틀 정리

직접 입력할 때 이 순서를 지킵니다.

```
저자. (연도). 제목. 저널명 또는 학회명, 권(호), 시작쪽-끝쪽.
```

지켜야 할 규칙은 넷입니다.

- **영문 저자**는 `성, 이니셜.` 형태로 쓰고 마지막 저자 앞에 `&`를 넣습니다
  `Lee, K., Lim, H., Kim, I., & Lee, S.`
- **국문 저자**는 쉼표로만 잇습니다. `&`는 쓰지 않습니다
  `황정윤, 김덕우, 임현우`
- **연도는 괄호** 안에 넣고 뒤에 마침표를 찍습니다
- **문장 끝에 마침표**를 찍습니다

학회명 뒤에 개최지나 개최 월을 붙이지 마세요. 날짜는 날짜 칸이 이미 갖고 있습니다.

```
잘못: ... (ISAIA 2024). September, Kyoto, Japan.
맞음: ... (ISAIA 2024).
```

> 저널명은 사이트에서 **자동으로 기울임 처리**됩니다. 인용문 끝이 `저널명, 권, 쪽.` 형태여야 인식하므로 위 틀을 지켜 주세요. 인식에 실패해도 글자는 그대로 보이니 목록이 깨지지는 않습니다.

## 4. 나머지 항목

### 날짜

게재일 또는 발표일입니다. **이 날짜의 연도로 묶이고, 같은 해 안에서는 최신이 위로** 자동 정렬됩니다. 목록에서 순서를 옮길 필요가 없습니다.

### DOI

**반드시 `https://doi.org/10.****/...` 형태로 넣습니다.**

저널 사이트 주소를 그대로 넣으면 안 됩니다. ScienceDirect 같은 사이트는 외부에서 바로 들어오는 요청을 막기 때문에 링크가 열리지 않습니다.

```
잘못: https://www.sciencedirect.com/science/article/pii/S0378778826006006?via%3Dihub
맞음: https://doi.org/10.1016/j.enbuild.2026.117540
```

`10.`으로 시작하는 부분만 논문 페이지에서 찾아 `https://doi.org/` 뒤에 붙이면 됩니다. `10.1016/...`처럼 앞의 주소 없이 넣어도 링크가 깨집니다.

학회 발표는 대개 DOI가 없습니다. 비워 두세요.

### 배지

**저널에만 있습니다.** SCIE, SCOPUS, KCI 중에 고릅니다.

비워 두면 국제 저널은 SCIE, 국내 저널은 KCI가 자동으로 붙습니다. **SCOPUS일 때만 직접 고르면 됩니다.**

학회는 배지 칸이 아예 없습니다. 국제 학회는 `INT. CONF.`, 국내 학회는 `DOM. CONF.`가 자동으로 붙습니다.

### 연구실 공저자

**비워 두셔도 됩니다.** 저장하면 자동으로 채워집니다.

**제1저자는 넣지 않습니다.** 제1저자는 인용문의 첫 저자로 따로 잡히고, 개인 프로필에는 그 사람 논문만 올라갑니다. 이 칸은 제1저자를 뺀 나머지 연구실 공저자만 담습니다. 지도교수와 외부 공저자도 넣지 않습니다.

교수님과 학생 한 명이 쓴 논문이라면 이 칸은 **비어 있는 것이 정상**입니다.

자동 판별은 이름 전체를 봅니다. 국문 논문은 한글 이름으로, DOI가 있는 영문 논문은 Crossref의 저자 이름 전체로 대조합니다. 이니셜만으로는 `Lim, J.`가 임지수인지 임종연인지 알 수 없어서 이름 전체가 확인될 때만 붙입니다.

**직접 고르면 자동 보완이 덮어쓰지 않습니다.** 일부러 뺀 사람은 그대로 빠져 있습니다.

### 관련 연구 주제

**여기서 고른 연구 상세 페이지의 "관련 논문"에 자동으로 뜹니다.** 해당 없으면 비워 둡니다.

한 논문이 여러 연구 주제에 걸쳐 있으면 여러 개를 고르면 됩니다.

### 수상

**우수논문상**과 **우수논문발표상** 두 가지가 있습니다. 받은 상이 없으면 비워 둡니다.

고를 때 기준은 하나뿐입니다. **상장에 적힌 이름을 그대로 고릅니다.** 저널 논문인지 학회 발표인지로 짐작하면 안 됩니다. 학회 발표인데 우수논문상을 받은 경우가 실제로 있습니다.

기억으로 고르지 말고 상장이나 학회 공지를 확인하세요. 학회마다 `우수발표논문상`처럼 어순이 다른 이름을 쓰기도 하는데, 그런 경우 사이트에서는 위 두 가지 중 가까운 쪽으로 통일해 표시합니다.

고르면 목록에 🏆와 함께 상 이름이 그대로 표시됩니다.

## 5. 저장하면

자동으로 저장소에 커밋되고 1~2분 뒤 사이트에 반영됩니다.

## 6. 논문 하나가 세 곳에 나옵니다

CMS에 한 번만 넣으면 됩니다. 예전에는 프로필과 연구 페이지에 같은 논문을 또 적어야 했는데, 이제 태그로 연결됩니다.

| 화면 | 무엇이 나오나 |
|---|---|
| Publications 탭 | 전부 |
| 멤버 개인 프로필 | 자기가 **제1저자**인 논문 |
| 연구 상세 페이지 | **관련 연구 주제**에 그 페이지가 들어간 논문 |

`members.json`이나 `research.json`을 손댈 필요가 없습니다. 논문 정보는 `publications/` 네 파일에만 있습니다.

### 새 학생이나 새 연구 주제가 생기면

**CMS 드롭다운은 자동으로 따라옵니다.** 따로 손댈 것이 없습니다.

- 학생: `members.json`에 추가하면 됩니다 (People 페이지에 넣는 그 작업)
- 연구 주제: 연구 상세 페이지를 만들면 됩니다 (`research-content/research.json` 또는 `index.html`)

저장소에 올라오면 자동화가 `.pages.yml`의 선택 목록을 다시 만듭니다. 설정 파일을 직접 고칠 필요가 없습니다.

> `.pages.yml` 맨 위의 `_lab_members`와 `_research_pages`는 **자동으로 생성되는 목록**입니다. 손으로 고쳐도 다음 실행 때 덮어써집니다. 명단을 바꾸려면 `members.json`을 고치세요.

## 7. 데이터 구조 (참고)

파일은 종류별로 넷입니다. 어느 파일에 들어 있는지가 곧 종류이므로 `category` 필드는 없습니다.

```json
{
  "citation": "Lee, K., Lim, H., Kim, I., & Lee, S. (2025). Data-driven methodology for identifying gross floor area thresholds in building energy benchmarking. Journal of Building Engineering, 112, 113768.",
  "date": "2025-10-15",
  "doi": "https://doi.org/10.1016/j.jobe.2025.113768",
  "badge": "SCIE",
  "first": "kyungjae",
  "members": ["sangmin"],
  "research": ["research-chpwh"],
  "award": "우수논문발표상"
}
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `citation` | 예 | APA 인용문 한 줄 |
| `date` | 예 | `YYYY-MM-DD`. 정렬과 연도 표시에 쓰입니다 |
| `doi` | 아니오 | `https://doi.org/...` 형태 |
| `badge` | 아니오 | 저널만. `SCIE`, `SCOPUS`, `KCI` |
| `first` | 자동 | 제1저자 slug. 개인 프로필은 이 값만 봄 |
| `members` | 아니오 | 제1저자를 뺀 연구실 공저자. 없으면 필드 자체가 없음 |
| `research` | 아니오 | 연구 페이지 id 목록. 그 페이지에 표시됨 |
| `award` | 아니오 | `우수논문상` 또는 `우수논문발표상` |

사이트는 `date` 내림차순으로 자동 정렬합니다.

설정 파일은 저장소 루트의 `.pages.yml`입니다.
